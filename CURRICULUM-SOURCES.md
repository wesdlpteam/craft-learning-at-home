# Curriculum sources and adaptations

The Maths topic picker contains parent-friendly adaptations of all 240 Australian Curriculum Version 9.0 Mathematics content descriptions for Foundation–Year 10, excluding the optional Year 10A content. It does not reproduce elaborations or achievement standards. English, Science and senior years use general suggestions, not mapped curriculum topics.

## What was changed

Each source content description has an original short plain-language label. The app groups these labels into six familiar topic categories and generates parent or student wording. Simplified labels are navigation aids; the unchanged official description, code, version and source are included in the copied prompt when a curriculum skill is selected.

Selecting a different topic level does not change the learner's school year. Editing the generated difficulty removes the curriculum reference, to avoid attaching an unrelated code to custom text.

## Maintenance and checks

Data is bundled locally in curriculum-maths.js; there is no live curriculum service or API key. Updates require a reviewed app release. The current data was checked against all 240 source descriptors for matching codes, years, strands and official descriptions. The labels are adaptations, not an ACARA-approved translation. Run node scripts/check-curriculum.cjs for structural coverage checks and review wording against the linked source when changing labels.
